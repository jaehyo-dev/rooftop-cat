## 정한 수치 (scripts/balance.gd "줄줄이" 절)
- 만남: 첫 10~15초, 그 뒤 15~25초 (봇 8판 측정: 첫 11.2~15.1초, 간격 15~25초). 화면 오른쪽 밖 옥상, 장애물·트램펄린·아이템 150px 밖, 그 자리 땅 생선은 치움.
- 간격: 주인공~첫 고양이 105px, 그 뒤 92px (80은 캡처에서 몸이 겹쳐 넓힘). 길고양이 크기 0.75배.
- 배수 = 1 + 0.2 x 마리 (1마리 x1.2 … 6마리 x2.2). 거리 점수와 생선 점수에 곱함. 피버 5마리부터.
- 데려온 고양이 = 판이 끝날 때 줄에 남은 수 (떨어져 끝나도 그때 줄에 있던 수).

## 앞이 보이는 시간 (6마리, 가장 빠른 속도 950px/초)
줄이 길면 주인공을 화면 오른쪽으로 옮김: 0~3마리 340px(그대로), 6마리 635px.
| 화면 | 지금(줄 없음) | 6마리 | 변화 |
|---|---|---|---|
| PC 1280 | 940px = 0.99초 | 645px = 0.68초 | -31% |
| 휴대폰 (게임 폭 1558) | 1218px = 1.28초 | 923px = 0.97초 | -24% |
PC 6마리에서 앞이 0.68초뿐이라 빠른 단계에서 위험해질 수 있음. 사용자가 느낌을 본 뒤 정할 것: 간격 줄이기(겹침), 6마리 때 화면 살짝 멀리(질주처럼 0.92배), 또는 이대로.

## 알려진 한계 (시험판)
- 길고양이 그림은 주인공 그림 색만 바꾼 것: 목도리 자리는 연한 털 목둘레로 보임.
- 맨 뒤 고양이가 화면 왼쪽 끝 가까이 있어 도망가는 모습이 조금 잘림.
- 비둘기 떼(주인공 x 기준으로 움직임)는 따라오는 고양이와 그림이 잠깐 겹칠 수 있음 (판정 없음).
- 따라오는 고양이는 판정이 없다(기록 재생만). 주인공이 지난 길이라 항상 무사.
