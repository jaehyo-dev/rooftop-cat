# 떠다니는 아기 "구름 타고 날기": 치즈냥 먼저 (2026-11-20, cat-parade 브랜치, 버전 그대로)

사용자 지적(2026-11-20): 고양이가 떠다니는 게 아직 어색하다.
디렉터 판단: (1) 앉아 기다리는 자세로 빠르게 날아가 스티커를 끄는 것처럼 보임, (2) 위아래로만 늦게 따라오고 앞뒤는 고정이라 속도감이 없고 방석은 받침대일 뿐, (3) 주인공이 화면 왼쪽이라 6마리가 좁은 칸에 비스듬히 쌓임.
바꾼 것: 구름에 엎드려 타는 그림, 앞뒤 출렁임·물결·구름 꼬리 조각, 혜성 꼬리 줄과 주인공 옮기기. 예전 방식은 시험 단추 **"아기 타기: 예전(앉기) / 새(구름 타기)"**로 바꿔 볼 수 있다 (`bash tools/play_local.sh` → 왼쪽 아래 "시험판 임시").
다른 5마리는 아직 앉은 그림이라 새 방식에서도 탄 구름 위에 앉아 있다.

## 3단계: 줄 모양
- 혜성 꼬리: 맨 앞은 주인공 발끝에서 뒤 108px·위 73px(주인공 등 높이 조금 위, 세운 꼬리 끝과 안 겹침), 뒤로 한 칸마다 61px·4px만 높아짐.
- 주인공 옮기기: 줄(맨 뒤 구름 꼬리 끝)이 화면 왼쪽 12px 안에 들어가도록 필요한 만큼만 오른쪽으로, 최대 60px (3마리까지 0, 4마리 16, 5·6마리 60px). 마리 수가 바뀌면 0.5초에 걸쳐 smoothstep. 세계 그림·그림자·말풍선·앞 시야(`sim.view_ahead`)도 같이 옮김 (`world_view.cat_x()`).
- 그래도 모자라면 간격을 좁힘 (판단: 원근감 축소보다 단순하고, 작은 아기가 더 작아지면 안 보임). 5마리는 간격 61 → 57px, 6마리는 45px (하한 0.7배 = 43px).
- 생선 수 아래·주인공 얼굴 안 가리기·아기를 주인공 위 층에 그리기는 그대로 (자동 테스트 그대로 통과).

### 앞 시야 측정 (`sight_report.gd`, 결과 `sight_report.txt`)
지금 봇(`tests/balance_bot.gd`)은 앞을 다 아는 계획이라 시야가 상관없어, **시야 모델**을 선택 옵션으로 넣었다: 넘을 것(다음 옥상·장애물)이 화면 오른쪽 끝에 들어온 뒤 0.3초가 지나야 누를 수 있다. 앞 시야 = 940px(PC 1280 폭) - 그때 아기 수로 옮긴 폭. 시드 20개, 판 최대 600초, 아기 무리 켬.

| 실력 | 안 옮김 평균 | 최대 60px 평균 | 변화 | 가운데값 변화 |
|---|---|---|---|---|
| 초보 | 580m | 577m | -0.6% | 633 → 633 |
| 익숙함 | 923m | 935m | +1.4% | 770 → 704 (-8.6%) |
| 숙련 | 882m | 963m | +9.2% | 702 → 692 (-1.4%) |

- 평균은 5% 넘게 나빠지지 않아 60px를 그대로 두었다. 다만 솔직히: **익숙함의 가운데값은 8.6% 줄었고**, 평균이 오른 쪽도 있어 이 차이는 시드 20개의 잡음 수준이다(판이 갈라지면 결과가 크게 달라짐).
- 처음에 판 내내 880px(6마리 고정, 가장 나쁜 경우)로 재면 익숙함 -30%, 숙련 -28.5%였다. 실제 판은 아기가 15~25초마다 하나씩 늘어 5~6마리인 시간이 짧아 영향이 작다. 오래 버티는 사람일수록 6마리 시간이 길어지니 디렉터가 직접 해 보고 판단해 주면 좋겠다.
- 이 모델 자체가 빠른 속도에서 꽤 엄격하다(모델 없음 대비 숙련 5192m → 882m). 사람은 리듬으로 미리 예측하므로 실제 영향은 이보다 작을 것으로 본다.

## 여전히 어색한 점 (숨기지 않음)
1. 착지 순간 뒤 아기들이 위에 남아 아치·기둥처럼 보임 (위 표). 줄 지연(0.12초 x 순서)을 타기 방식에서만 줄이거나, 아래로 내려올 때 더 빨리 따라오게 하는 방법을 다음에 검토할 수 있다.
2. 앉은 그림으로 이어지는 동작(밟기 만세·놀람·하품·그루밍·꾹꾹이·뒤돌아보기)은 엎드린 타기 자세에서 앉은 자세로 확 바뀐다. 타는 자세 버전 그림이 필요하다.
3. 펄럭임 3장 중 ride_0의 머리가 ride_1·2보다 조금 높아(귀를 세움) 반복할 때 머리가 살짝 오르내린다. 바람에 흔들리는 것처럼 보이기도 하지만, 2배 확대에서는 보인다.
4. 6마리 평지에서 치즈냥의 날리는 꼬리가 바로 뒤 아기(삼색이) 얼굴 앞까지 닿는 장이 있다 (치즈냥이 위 층이라 덮음). 실제 크기에서는 작다.
5. 맨 앞의 늘어짐은 19px라 실제 속도에서 약하다. 더 키우면 6마리 맨 뒤가 화면 밖으로 밀린다.
6. 처음 6마리로 시작할 때 주인공이 0.5초에 걸쳐 오른쪽으로 옮겨지는 동안 세계가 잠깐 느려 보일 수 있다 (판 중에는 아기가 하나씩 늘어 4마리 16px → 5마리 60px로 나눠 옮겨짐).
