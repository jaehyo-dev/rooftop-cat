# 떠다니는 아기 살아 움직이기: 치즈냥 먼저 (2026-11-19, cat-parade 브랜치, 버전 그대로)

사용자 지적: "아기 고양이 모션이 멈춰 있어서 그냥 그림이 둥둥 떠다니는 것 같다." 디렉터 확인: 떠다니는 아기는 wait.png 한 장만 썼다.
배치(줄줄이)는 그대로 두고 아기 자체의 움직임을 만들었다. 0.28배로 작게 보여서 실루엣이 바뀌는 큰 동작 위주이고, 그림을 통째로 돌리거나 흔들지 않는다.
설계는 `scripts/logic/kitten_life.gd`(KittenLife)와 GAME_SPEC "떠다니기" 절에 있다. 다른 5마리는 아직 예전처럼 둔다.

## 그림 (1단계)
- Codex 시트 1장, 다시 뽑기 0번 (`make_sheet.sh`, 요청문 `prompts/alive.txt`, 첨부 `prompts/ref_cheese_wait.png`, 원본 `assets/raw/kitten_alive/cheese_1.png`).
- 자르기: `python3 tools/cut_kitten_alive.py assets/raw/kitten_alive/cheese_1.png assets/sprites/kittens/cheese` → `alive_<이름>.png` 14장 + `alive_tail_0~4.png`.
  캔버스 256x240, 발끝 기준선 216, 엉덩이 왼쪽 끝 x 68 (모든 장이 같음, 자동 측정).
- `cheese_sheet.png`: 14장 2배. `cheese_onion.png`: 장마다 빨간 선 = 쉬는 그림(alive_base) 윤곽, 파란 선(첫 칸) = 예전 wait.png 윤곽, 초록 줄 = 발끝 기준선.
- 내가 판단한 것: 새 그림은 wait.png보다 머리가 조금 작게 그려져서(같은 넓이 기준) wait.png와 섞으면 머리 크기가 튄다. 그래서 시트의 "기본" 칸을 쉬는 그림으로 쓰고, 꼬리도 그 칸에서 떼어 `alive_tail_0~4`로 만들었다. 이렇게 모든 장이 한 시트에서 나온다. 기본 칸과 wait.png의 겹침은 87% (파란 선과 빨간 선이 거의 같은 자리).
- 꼬리: 세운 꼬리는 따로 붙여 늘 살랑이게 했다. 엎드리기·놀람·폭 앉기 3장은 자기 꼬리를 쓴다. 엎드리기는 꼬리가 바닥에 깔리고, 놀람은 꼬리털이 부풀고, 폭 앉기는 등이 낮아서 따로 붙인 꼬리 뿌리가 드러나기 때문이다.
  처음에는 만세·하품에 원래 꼬리가 남아 꼬리가 둘로 보였고, 폭 앉기에서는 꼬리 뿌리가 계단처럼 보였다. 꼬리 자리와 엉덩이 쪽 윤곽 밖을 지워서 고쳤다(확대 확인).

| 묶음 | 그림 | 쓰는 때 |
|---|---|---|
| 늘 | base, blink, alive_tail_0~4 | 쉬기, 깜빡임(2~5초 무작위, 0.12초), 꼬리 살랑(아기마다 2.0~2.9초), 숨쉬기(1.5%, 아기마다 1.8~2.5초) |
| 반응 | cheer_0·cheer_1 | 점프·더블점프·밟기 만세. 맨 앞은 점프 순간, 아기 i는 i x 0.12초 늦게 (간격이 줄 출렁과 같고, 각 아기가 떠오르기 0.12초 전에 앞발을 듦) |
| | squat | 착지 때 폭 앉기(0.16초 안팎, 아기 i가 실제로 내려앉는 (i+1) x 0.12초). 슬라이딩에 들어갈 때와 나올 때 사이 장 |
| | lie | 슬라이딩 동안 엎드리기 |
| | squat → surprised | 다른 아기가 피격으로 날아갈 때 놀람(0.6초 안팎) |
| 가끔 | yawn_0·1, groom_0·1, knead_0·1, look | 하품·그루밍·꾹꾹이·뒤돌아보기. 아기마다 6~12초 간격, 화면 전체에서 한 마리씩, 같은 행동은 이어서 안 함, 가장 긴 장 길이는 매번 0.75~1.35배 |

## 확인 영상 (3단계)
치즈냥이 줄 맨 앞(6마리)에 있고, 같은 시드에 속도 600 고정, 능력은 쓰지 않는다.

| 파일 | 장면 |
|---|---|
| `<장면>_real.mp4` / `<장면>_slow.mp4` | 실제 속도 / 0.25배 (생선 수부터 주인공 앞까지) |
| `<장면>_zoom_real.mp4` / `<장면>_zoom_slow.mp4` | 치즈냥 둘레 2배 (기록한 발끝 자리를 따라 자름) |
| 장면 | `flat` 평지 10초(0.25배는 앞 4초) · `jump` 점프 · `double` 더블점프 · `slide` 슬라이딩 · `stomp` 밟기 3연속 · `hit` 화분에 피격(줄 끝 아기가 날아감) |

다시 만들기: `GODOT=<경로> bash review/v0.7.0/2c-juice/export_qa.sh` → `PLAYWRIGHT=<경로> node review/cat-parade/qa_web.mjs build/qa <폴더> parade_alive x pc` (장면 하나만: `parade_alive-jump`) → `python3 review/cat-parade/action/alive/make_videos.py <폴더>`. 그림 확인 시트: `python3 review/cat-parade/action/alive/onion.py cheese`.

## 프레임을 한 장씩 보고 확인한 것
0.25배 확대 장을 늘어놓아 봤고(만세 타이밍을 고친 뒤 점프·더블점프·밟기는 다시 찍음), 기록한 발끝 자리에 14장을 대 보아 장마다 어느 그림인지 뽑았다(실제 속도 30장/초 기준).

| 장면 | 치즈냥 그림 차례 (장 수) |
|---|---|
| 점프 | base → 점프 순간(5장째) cheer_0 2 → cheer_1 9 → cheer_0 2 → base 14 → 착지 squat 3 → base |
| 더블점프 | 만세 → 더블점프에서 다시 cheer_0 4 → cheer_1 9 → base → 착지 squat 6 → base |
| 슬라이딩 | base → (주인공 몸에 가린 4장) → lie 28 → 일어나며 squat 4 → base |
| 밟기 3연속 | 밟을 때마다 cheer_0 → cheer_1 → cheer_0, 착지 squat 5 → base |
| 피격 | squat → surprised (끝까지 놀람 자세, 사이에 다른 그림 없음) → base |
| 평지 10초 | 쉬기(꼬리·숨·깜빡) → 8초쯤 look 34장(1.1초) → 쉬기 |

| 확인 | 결과 |
|---|---|
| 그림이 튀거나 깜빡이는 장 | 없음. 분류가 섞여 나온 곳(슬라이딩 시작, 피격 중)을 직접 보니 주인공 몸·빨간 피격 깜빡임이 아기를 가린 장이었다 |
| 기준점 | 14장 모두 발끝 216·엉덩이 x 68이라 바꿔 끼워도 발과 엉덩이가 구름에서 뜨지 않는다. 숨쉬기와 기울기도 발끝 원점을 기준으로 한다 |
| 실제 속도에서 보이는가 | 만세(0.3초 앞발 위, 머리 위로 실루엣이 높아짐), 엎드리기(키 60%), 뒤돌아보기(얼굴 방향), 놀람(꼬리털)은 잘 보인다. 착지 폭 앉기는 3~5장(0.1~0.16초)이라 짧은 "꾹"으로 보인다 |
| 기계적 반복 | 가끔 하는 행동은 간격·길이가 무작위이고 같은 것이 이어서 안 나온다(자동 테스트). 밟기를 연속으로 하면 만세도 연속으로 나오는데, 반응이라 그대로 두었다 |

자동 테스트 `tests/test_kitten_life.gd`가 확인하는 것: 만세 차례((i+1) x 0.12초), 반응이 하던 행동을 끊음, 가끔 하는 행동은 한 번에 한 마리이고 같은 아기는 6초 이상 쉬며 같은 행동을 이어서 안 함(4가지 모두 나옴), 슬라이딩 엎드림과 일어나며 폭 앉기, 놀람, 깜빡 간격 2~5초, 박자가 아기마다 다름, 같은 시드면 같은 움직임, 숨 1~2%, 그림 14장이 같은 캔버스.

## 함께 고친 것
- 무리 기울기(`KittenFlock.tilt`)가 화면에 안 나오던 버그: world_view가 기울기를 넣은 뒤 `show_sit`이 rotation을 0으로 되돌렸다. 기울기를 그린 뒤에 넣어서 6마리 모두 이제 기울어진다(최대 10도, 배치 단계 설계값).

## 알려진 것
- 평지 10초에는 가끔 하는 행동이 1번(뒤돌아보기)만 나온다(간격 6~12초). 하품·그루밍·꾹꾹이는 시트 그림으로 확인할 수 있고, 게임에서는 더 오래 달려야 나온다.
- 꾹꾹이는 앞발 높이만 바뀌어서 0.28배에서는 잘 안 보인다(실루엣 변화가 가장 작다).
- 슬라이딩 시작 0.13초 동안 주인공 꼬리가 맨 앞 아기를 덮는다(배치 단계 README에 있던 것).
- 화면 전체에서 한 마리만 가끔 행동을 한다는 규칙은 지금 그림이 있는 치즈냥에게만 적용된다(`idle_ok`, `shortcut:` 주석). 6마리 그림이 생기면 지운다.
- 프레임 사이 겹침(크로스페이드)은 넣지 않았다. 만세·하품 등에 사이 장(cheer_0, yawn_0 등)이 있고, 엎드리기 앞뒤에는 폭 앉기를 끼워서 실제 속도에서 끊겨 보이지 않았다.
