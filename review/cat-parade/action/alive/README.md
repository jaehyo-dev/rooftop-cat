# 떠다니는 아기 살아 움직이기: 치즈냥 먼저 (2026-11-19, cat-parade 브랜치, 버전 그대로)

사용자 지적: "아기 고양이 모션이 멈춰 있어서 그냥 그림이 둥둥 떠다니는 것 같다." 디렉터 확인: 떠다니는 아기는 wait.png 한 장만 썼다.
배치(줄줄이)는 그대로 두고 아기 자체의 움직임을 만들었다. 0.28배로 작게 보여서 실루엣이 바뀌는 큰 동작 위주이고, 그림을 통째로 돌리거나 흔들지 않는다.
설계는 `scripts/logic/kitten_life.gd`(KittenLife)와 GAME_SPEC "떠다니기" 절에 있다. 다른 5마리는 아직 예전처럼 둔다.

## 그림 (1단계)
- Codex 시트 1장, 다시 뽑기 0번 (`make_sheet.sh`, 요청문 `prompts/alive.txt`, 첨부 `prompts/ref_cheese_wait.png`, 원본 `assets/raw/kitten_alive/cheese_1.png`). 지금 게임 그림은 위 "다듬기"의 `cheese_2.png`.
- 자르기: `python3 tools/cut_kitten_alive.py assets/raw/kitten_alive/cheese_2.png assets/sprites/kittens/cheese` → `alive_<이름>.png` 14장 + `alive_tail_0~4.png`.
  캔버스 256x240, 엉덩이 왼쪽 끝 x 69 (모든 장이 같음, 자동 측정). 발끝은 기준선 216보다 1px 위 215 (테두리를 1px 깎아서, 게임에서 0.3px라 그대로 둠).
- `cheese_sheet.png`: 14장 2배. `cheese_onion.png`: 장마다 빨간 선 = 쉬는 그림(alive_base) 윤곽, 파란 선(첫 칸) = 예전 wait.png 윤곽, 초록 줄 = 발끝 기준선.
- 내가 판단한 것: 새 그림은 wait.png보다 머리가 조금 작게 그려져서(같은 넓이 기준) wait.png와 섞으면 머리 크기가 튄다. 그래서 시트의 "기본" 칸을 쉬는 그림으로 쓰고, 꼬리도 그 칸에서 떼어 `alive_tail_0~4`로 만들었다. 이렇게 모든 장이 한 시트에서 나온다. 기본 칸과 wait.png의 겹침은 87% (파란 선과 빨간 선이 거의 같은 자리).
- 꼬리: 세운 꼬리는 따로 붙여 늘 살랑이게 했다. 엎드리기·놀람·폭 앉기 3장은 자기 꼬리를 쓴다. 엎드리기는 꼬리가 바닥에 깔리고, 놀람은 꼬리털이 부풀고, 폭 앉기는 등이 낮아서 따로 붙인 꼬리 뿌리가 드러나기 때문이다.
  처음에는 만세·하품에 원래 꼬리가 남아 꼬리가 둘로 보였고, 폭 앉기에서는 꼬리 뿌리가 계단처럼 보였다. 꼬리 자리와 엉덩이 쪽 윤곽 밖을 지워서 고쳤다(확대 확인).

|---|---|---|
| 늘 | base, blink, alive_tail_0~4 | 쉬기, 깜빡임(2~5초 무작위, 0.12초), 꼬리 살랑(아기마다 2.0~2.9초), 숨쉬기(1.5%, 아기마다 1.8~2.5초) |

## 알려진 것
- 평지 10초에는 가끔 하는 행동이 1번(뒤돌아보기)만 나온다(간격 6~12초). 하품·그루밍·꾹꾹이는 시트 그림으로 확인할 수 있고, 게임에서는 더 오래 달려야 나온다.
- 꾹꾹이는 앞발 높이만 바뀌어서 0.28배에서는 잘 안 보인다(실루엣 변화가 가장 작다).
- 평소 달리기에서도 몸을 쭉 뻗는 달리기 그림(run_1·run_2, 꼬리 끝 x -132~-111·높이 -79~-100)이 나올 때 주인공 꼬리 끝이 맨 앞 아기 머리 쪽을 살짝 덮는다(배치 단계부터 있던 것, 이번 지적 범위 밖). 없애려면 줄을 늘 뒤로 물려야 하는데 그러면 4마리도 굽어서 "4마리 이하 한 줄" 요구와 부딪힌다. 다른 방법(아기를 조금 낮추기, 달리기 동안만 아기를 주인공 위에 그리기)은 디렉터 판단으로 남김.
- 슬라이딩에 들어가는 순간 줄이 한 프레임에 52px 뒤로 옮겨진다(겹침 0을 위해, 주인공 그림도 같은 프레임에 바뀜). 0.05초에 걸쳐 옮기면 1~2장 겹친다.
- 요정 무리(비교용 배치)는 슬라이딩 비키기를 넣지 않았다.
- 화면 전체에서 한 마리만 가끔 행동을 한다는 규칙은 지금 그림이 있는 치즈냥에게만 적용된다(`idle_ok`, `shortcut:` 주석). 6마리 그림이 생기면 지운다.
- 프레임 사이 겹침(크로스페이드)은 넣지 않았다. 만세·하품 등에 사이 장(cheer_0, yawn_0 등)이 있고, 엎드리기 앞뒤에는 폭 앉기를 끼워서 실제 속도에서 끊겨 보이지 않았다.
