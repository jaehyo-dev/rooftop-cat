# 떠다니는 아기 배치 다시 만들기 (2026-11-19, cat-parade 브랜치, 버전 그대로)

사용자 지적: "작을수록 좋지만 아기 배치와 떠다니는 게 너무 어색하다." 디렉터가 본 원인은 피라미드가 진열장처럼 보임, 구름이 겹쳐 한 덩어리, 무리가 덩어리째 늦게 따라옴, 같은 앉은 그림이 위아래로만 흔들림이었다.
설계·수치는 `scripts/logic/kitten_flock.gd`(KittenFlock)와 `scripts/balance.gd`의 `KITTEN_CHAIN_*`·`KITTEN_FLOCK_*`, GAME_SPEC "떠다니기" 절에 있다.

## 바뀐 것
- 크기 기본값: 작게(0.28배). 시험 단추 "아기 크기"는 그대로.
- 시험 단추 "아기 배치: 줄줄이 / 요정 무리" (기본 줄줄이, 로컬 빌드에만).
- 줄줄이: 주인공 발끝 높이를 기록해 두고, 아기 i는 (i+1) x 0.12초 전 높이를 따라간다. 점프하면 앞에서부터 차례로 출렁인다. 간격은 구름 폭보다 조금 넓게(구름 타원 거리 54px). 4마리까지는 한 줄, 5·6마리는 화면 왼쪽을 넘지 않게 가로 간격을 줄이는 만큼 위로 비스듬히 올린다.
- 요정 무리(비교용): 주인공 뒤쪽 위 둥근 구역에서 아기마다 작은 원(짝수)·8자(홀수) 궤도를 다른 박자로. 따라오는 스프링 빠르기가 아기마다 0.7~1.3배.
- 공통: 구름끼리 겹치면 밀어냄, 지붕 아래·생선 수 위로 안 감, 움직이는 방향으로 최대 10도 기울기(올라갈 때 뒤로, 내려올 때 앞으로), 내려올 때 구름 방석이 납작해졌다 돌아옴, 둥실 박자 아기마다 다름, 보이는 자리는 1600px/초보다 빨리 안 움직임.
- 피격: 줄 맨 끝(가장 나중) 아기가 날아가고 남은 줄이 5마리 모양으로 이어서 옮겨 감. 새 아기: 기다리던 옥상에서 줄 끝으로 날아옴(900px/초 이하, 날아오는 동안은 다른 아기를 밀지 않고 지나감).
- 앞 아기가 뒤 아기 위에 그려진다. 슬라이딩 때는 아기들이 30px 비켜 올라간다(예전엔 22px 내려감).

## 알려진 것
- 6마리 줄은 생선 수까지 남은 높이가 적어(약 60px) 큰 점프에서는 무리 모양 그대로 눌린다. 더블점프 꼭대기에서 줄 뒤쪽이 지그재그로 접히는 장이 있다(구름은 안 겹침).
- 6마리 줄은 비탈이라 다시 "계단"처럼 보일 수 있다. 4마리까지는 한 줄.
- 슬라이딩을 시작하는 순간 0.1초쯤 맨 앞 아기가 주인공 꼬리 끝에 닿는다 (비켜 올라가는 것도 0.12초 늦게 따라가서).
- 합류하는 아기는 날아오는 동안 다른 아기 앞을 지나간다.
- 요정 무리는 6마리가 뭉쳐 보여 피라미드와 비슷한 느낌이 남는다 (비교용).
