## 합성에서 보인 문제 (그림을 넣을 때 정할 것)
- 새 아기 그림은 게임 크기에서 폭 약 110px(꼬리 포함, 몸만 약 98px)인데 줄 간격은 69px라, **앞 아기 꼬리가 뒤 아기 얼굴을 가리고 첫 아기 얼굴도 주인공 엉덩이에 조금 가린다.** 지금 색칠 고양이는 꼬리를 높이 세워 달려 덜 보였던 것.
- 안 겹치려면 간격 약 100px → 6마리 때 PC 앞 시야 0.80초 → 약 0.64초. 크기·간격·앞 시야를 다 지키기 어렵다.
- 고르는 길: (1) 달리는 자세를 꼬리를 세운 모습으로 다시 그리기(간격 69 유지, 코가 앞 꼬리 밑에 들어감), (2) 줄을 "옹기종기 겹친 무리"로 받아들이기, (3) 간격 100 + 6마리 때 화면을 살짝 멀리(질주처럼). 크기만 줄이면 간격도 같이 줄어 겹침은 그대로라 답이 아님.
