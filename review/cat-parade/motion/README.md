# 아기 고양이 움직임 A·B 비교 (2026-11-15, cat-parade 브랜치, 버전 그대로)

사용자 피드백: "뛸 때 그림을 좌우로 흔드는 것처럼 보이고, 바닥에 붙어 있는 느낌도 안 나." 치즈 아기 한 마리로 두 방식을 만들어 비교했다. 6마리로 늘리는 건 고른 뒤에 한다.

## 원인 확인 (디렉터가 본 원인 → 코드에서 확인)
| # | 디렉터 | 코드에서 본 것 |
|---|---|---|
| 1 | 아기가 주인공 달리기 프레임 번호를 그대로 재생 → 보폭 박자가 주인공 것 | 맞음. 다만 "시간"이 아니라 **주인공 보폭(CAT_STRIDE 150px) 기준 거리**로 넘어감. 0.56배 다리로 150px 보폭을 디뎌 발이 밀림 |
| 2 | AI로 그린 달리기 4장 몸통 위치가 장마다 달라 좌우로 흔들림 | 맞음. `cut_kittens.py`가 bbox(꼬리 뺀 불투명 가운데)로 맞춰, 다리 모양이 바뀌면 몸통이 옮겨짐 |
| 3 | 그림자 없음, 통통 튐이 몸 전체를 들어 올림 | **그림자는 있었음**(`_draw_parade`가 아기마다 그림). 통통 튐(3.5~6px)이 몸 전체를 올린 건 맞음. 하나 더: 주인공의 달리기 들썩임(lift, 4px)까지 기록에서 재생해 땅 위에서도 떠 있었음 |
| 4 | 도망이 그림 두 장을 위치만 옮김 | 맞음 (놀람·도망 그림 + 높이 곡선) |

## 두 방식
- **A 프레임 다시 그리기**: 달리기 8장 + 웅크림·도약·오름·내림·착지·멈칫 (`assets/sprites/kitten_motion/cheese_a/`). 자를 때 다리를 뺀 윗몸을 달리기 1장과 가장 많이 겹치게 맞춤(`tools/cut_kitten_motion.py`, `a_frames.png` = 파란 선 몸 중심·빨간 선 바닥·초록 디딘 발). 아기가 달린 거리로 장을 넘김(한 바퀴 149.5px, 장마다 18.7px).
  1차 시트는 AI가 발을 제자리에서 흔들어 디딘 발이 뒤로 가지 않음(미끄러짐 35~47px) → B와 같은 걸음새로 그린 안내도(`prompts/a_guide.png`)를 붙여 2차 시트를 씀.
- **B 조각 인형**: 몸통·머리·놀란 머리·다리 4·꼬리 (`cheese_b/`, 조립 확인 `b_rest.png`, Codex가 그린 조립 참고 `b_assembled.png`). 네 발이 차례로 디딤(한 발이 바퀴의 40%), 디딘 발의 세계 x를 그대로 두고 다리를 축 → 발로 돌리고 늘임. 한 바퀴 약 75px (다리가 짧아 950px/초에서 초당 약 13걸음).
- **공통**(`scripts/logic/kitten_motion.gd`, `kitten_view.gd`): 주인공 그림자 방식 축소 그림자, 땅 위에서는 몸을 들어 올리지 않고 발끝 축 세로 눌림만(걸음마다 1.5~3.5%, 착지 25%), 자세는 아기 상태(땅 = 달리기, 오름·내림 = 속도 방향으로 기울임·늘임, 닿는 순간 = 눌림 + 먼지). 도망 = 움츠림 → "!" 펄쩍 + 땀방울(줄 속도에서 끼익 멈춤) → 휙 돌기 → 몸을 숙여 다다다 뒤로. 만남 = 주인공이 오면 일어서서 주인공을 보고 들썩 → 웅크림 → 깡충(주인공 위) → 내려서 달려 줄 자리로(뒤로 밀려나지 않게 붙는 시간을 거리에 맞춤).
- 게임에서 보기: 로컬 시험 단추 "치즈 아기 움직임: A → B → 예전" (기본 A). 다른 5마리는 예전 그대로(만나 붙는 길만 새것).

**권하는 쪽: A.** 사용자가 말한 두 문제(좌우로 흔들림, 바닥에 안 붙음)는 A에서 몸통 기준 정렬·통통 튐 없앰·그림자·착지 눌림으로 풀렸고, 발 미끄러짐은 주인공의 절반 이하로 줄었다. B는 숫자로는 발이 완벽히 붙지만 세 검토자 모두 "종이 인형 같다"고 했고 그건 부품 그림 문제라 코드로 더 못 줄인다. 이 게임은 색연필 손그림이 정체성이라 그림이 덜 깨지는 쪽이 낫다. A의 남은 미끄러짐(장마다 18.7px)이 거슬리면 다음에 장 수를 12장으로 늘리는 걸 시험할 수 있다.

**디렉터가 정할 것**: 틈 점프 때 아기가 주인공 길(높이)을 그대로 따라가 "작은 몸이 높이·오래 떠 가볍다"는 지적이 세 번 모두 나왔다. 요구("주인공이 지난 길만 따라감")대로 두었다. 바꾸면 뛰는 자리·내려서는 자리는 같게 두고 가운데 높이만 0.7배로 낮추는 방법이 있다.

**남은 것 (6마리 때)**: 다른 5마리는 예전 그림·움직임 그대로(만나 붙는 길만 새것), 공중제비·트램펄린은 새 움직임 없음(오름·내림으로), 새 움직임 아기는 줄 안 겹침 순서(뒤 아기가 위)를 따르지 않음(한 마리라 생략).
