# 치즈 아기(A) 움직임 고침 (2026-11-16, cat-parade 브랜치, 버전 그대로)

사용자 결정(2026-11-16): 점프 길은 예전처럼 주인공이 지난 길(높이·시간) 그대로. 대신 앞 고양이의 동작을 제대로 따라 하고, 발은 땅에 붙고, 머리 흔들림이 어색하지 않게.

## 바꾼 것
| 요구 | 한 것 |
|---|---|
| 1. 점프 길 | 주인공 기록 그대로 (높이 0.7배 안은 버림). 트램펄린 오르는 길·매트 위 들어 올림도 기록 그대로 재생(기록 키 `tlift`, 주인공 달리기 들썩임은 뺌). 아기는 주인공이 누른 깊이의 0.2배만 따라 내려가고(기록 키 `mat`), 아기가 누르는 동안 그 트램펄린 그물은 주인공 반동(불룩·출렁임)을 끝낸 평평한 그물로 그림 (1·2·4·12차 검토) |
| 2. 동작 따라 하기 | 주인공이 기록할 때 그 장면의 아기 자세를 정해 기록에 넣고(`KittenMotion.air_pose`, 기록 키 `kpose`), 아기는 그 자리에서 재생. 주인공 그림 → 아기 그림: 웅크림·도약·오름·꼭대기(세로 속도 280 안)·내림·숙이기·C자·공·펴기·허우적·착지. 같은 자세가 0.1초를 넘으면 그 자세의 다음 순간 그림(`_b`)과 번갈아. 앞구르기는 주인공 회전, 허우적은 주인공 기울기 그대로. 주인공이 뛴 자리 0.07초 앞에서 미리 웅크림 (주인공 웅크림 0.03초는 안 보임, 1차 검토) |

| 3. 발 | 달리기 32장. 예전 8장의 다리를 쓰고 (`assets/raw/kitten_motion/a_run8`), 디딘 다리를 다리끼리 떨어진 줄 아래만 비스듬히 옮겨 디딘 동안 발의 세계 x가 같게 맞춤 + 장 사이에 디딘 다리만 더 기울인 사이 장 3장씩. 장마다 거리는 고친 그림을 발 미끄러짐 검사로 재서 가장 작은 값(한 바퀴 92 게임 px). 착지 그림은 0.05초만, 그동안 키를 달리기 키로 서서히 맞춰 바꿀 때 튀지 않게 (1·3차 검토). 웅크림(0.07초)·착지(0.05초) 그림을 붙잡는 동안 디딘 발이 바닥과 같이 흐르는 것은 알려진 절충 (9·10차에 발을 고정해 봤으나 11차에서 되돌림) |
| 4. 머리 | 윗몸(머리·몸통·꼬리)은 run_0 한 장을 모든 장에 그대로(목걸이·방울은 맨 위에 다시 덮음: 방울이 윗몸·다리 경계에 걸쳐 깜빡임, 4차 검토), 걸음 박자(한 바퀴 2번)에 맞춰 0~2 캔버스 px(0~1.2 게임 px)만 오르내림 |
| 버린 것 | 달리기 16장 새 시트(`a_run16_1.png`, 안내도 `prompts/a_guide16.png`): AI가 발 박자를 안내도대로 그리지 못해(장마다 디딘 발이 제멋대로, 미끄러짐 60~112px) 안 씀 |
