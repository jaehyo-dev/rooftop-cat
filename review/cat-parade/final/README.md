# 아기 움직임 6마리로 늘리기 + 놀란 얼굴 (2026-11-17, cat-parade 브랜치, 버전 그대로)

디렉터 결정(2026-11-17): 아기 움직임은 치즈 아기 motion2 수준에서 마무리. 더 다듬지 않고 같은 방식으로 6마리에 늘린다. 남은 것 중 "도망 때 웃는 얼굴"만 고친다. 나머지(달리기 몸 오르내림 크기, 트램펄린 그물 눌림, 웅크림·착지 순간 발 흐름)는 그대로 두고 PROGRESS "알려진 문제"에 적는다.

## 만든 것
| 단계 | 한 것 |
|---|---|
| 1. 놀란 얼굴 | 아기마다 놀람 시트 1장(놀란 달리기·놀라 움츠림·깜짝 펄쩍)을 Codex로 그려 `scared_upper`(달리기 위에 덮는 놀란 윗몸)·`scared_crouch`·`scared_hop`로 자름 (`tools/cut_kitten_motion.py scared`). 도망: 움츠림(끼익 멈춤) → 위로 솟는 펄쩍 → 서서 놀람(멈칫 그림) → 몸 돌림 → 놀란 윗몸을 덮은 달리기. 공중에서 놀라 내려앉을 때는 허우적(놀란 얼굴). 치즈로 먼저 만들어 확인(`scared6.png` 첫 줄) 뒤 나머지 |

## 알려진 것 (고치지 않음)
- 디렉터 결정으로 그대로: 달리기 몸 오르내림 크기(0~1.2 게임 px), 트램펄린 그물이 아기 무게로 눌리지 않음, 웅크림(0.07초)·착지(0.05초) 그림을 붙잡는 동안 디딘 발이 바닥과 같이 흐름.
- 도망: 맨 뒤 아기는 화면 왼쪽 끝(x 약 75)이라, 움츠림·펄쩍·몸 돌림은 줄과 같이 가며 보이지만 달아나는 부분은 네 장 만에 화면 밖.
- 턱시도 윙크가 실제 속도에서 깜빡여 보임 (그림은 같고, 줄여 그릴 때 가는 선이 장마다 옅어짐).
- 회색 놀란 윗몸의 삐친 털 테두리가 살짝 두 겹 (놀란 그림의 털 자리가 몇 px 다름, 게임 크기 약 2px).
- 그림 크기: 아기마다 300x260 그림 53장 (`kitten_motion` 16MB, 예전 아기 프레임 지워 0.75MB 남음). 6마리가 다 나오면 압축 안 된 텍스처 약 99MB, 처음 만나는 품종은 그 순간 53장을 읽음. 휴대폰 웹 메모리·끊김은 재지 않음.
