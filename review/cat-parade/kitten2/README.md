# 아기 고양이 그림을 게임에 넣기 (2026-11-15, cat-parade 브랜치, 버전 그대로)

시안 2 "개구쟁이 아기" 확정(이유는 GAME_SPEC "아기 고양이 디자인 확정"). 6마리 x 23장 = 그림 138장 + 얼굴 6장.

## 자세 목록 (주인공 → 아기)
주인공 프레임 `CatPose.ALL_FRAMES` 중 따라오는 아기가 재생하는 14장을 모두 그림: 달리기 4(run_0~3), 웅크림(crouch, 트램펄린에 눌림·뛰기 직전), 도약(takeoff), 오름(rise), 내림(fall), 착지(land), 허우적(flail, 떨어짐·트램펄린 실패), 공중제비 4(flip_tuck·curl·ball·open).
아기 전용: 기다리기(wait 몸 1장 + 꼬리 wait_tail_0~4, 옥상에서 꼬리 살랑), 놀람(scared, "!" 하고 뛰어오름), 도망(flee, 몸을 돌려 달아남). 주인공 앉기·일어남(sit_*)은 시작 화면 전용이라 아기에게 없음(일어남이 오면 달리기 1장).

## 정한 것
- 크기: 시트마다 달리기 4장 넓이 가운데값을 같게(모든 아기가 같은 크기). 그림은 작은 캔버스(256x240)에 원본 해상도 그대로 두고 게임이 2.5배 키워 0.56배로 그림(주인공 크기 캔버스로 키워 저장하면 흐리고 파일만 커짐).
- 기다리기 꼬리: 꼬리만 다른 그림 2~3장을 따로 뽑으면 몸이 장마다 달라 떨림 → 그림 1장에서 세운 꼬리를 떼어 뿌리 축으로 -8~8도 5장(주인공 `make_sit_tail.py`와 같은 방법). 젖소는 방울 꼬리라 떼지 않음(몸 그대로).
- 도망: 오른쪽을 보게 뒤집어 저장하고 게임이 뒤집어 그림(다른 프레임과 몸 중심 기준이 같게).
- 얼굴: 기다리기 몸에서 머리 전체(방울·나비넥타이 포함)를 잘라 UI 표의 받침처럼 쪽지 크림 원 + 갈색 테두리 배지에 넣음. HUD·결과 카드 56px(전 40, 폰에서 약 30px), 사이 4px. 얼굴은 아이마다 기다리기 그림에서 잰 머리 가운데·지름(`FACE_AT`)으로 원 가운데, 머리 = 배지의 78%.
- 도망: 놀람 그림은 뛰어오르는 시간의 35%만, 발끝 화면 높이 하한 300(줄이 공중이어도 머리·"!"가 HUD 숫자 아래), 뛰는 높이 60, "!"는 머리 바로 위.
- 높이 뜰 때: 따라오는 아기 발끝이 화면 y 255보다 위로 가면 넘은 높이의 12%만 더 올라가 머리가 왼쪽 위 HUD 숫자 밑에 깔리지 않음(그림만, 따라가는 길은 그대로).
- 같은 품종은 줄에 둘이 오지 않음(줄 최대 6 = 품종 6).

## 줄 배치 전후
그리는 순서: 전 = 앞 아기가 위(뒤 아기 얼굴을 앞 아기 꼬리가 덮음) → 지금 = 뒤 아기가 위(오리 새끼 줄, 뒤 아기 머리가 앞 아기 엉덩이 위). 주인공은 여전히 가장 위.
통통 튐: 전 = 2.5~4.5px, 아이마다 박자만 조금 다름 → 지금 3.5~6px, 초당 2.2~3번, 줄 자리마다 박자를 1.9라디안씩 어긋나게(테스트: 어느 순간에도 6마리 머리 높이 차 2px 넘음).
