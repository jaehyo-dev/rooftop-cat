예전 색연필 주인공 그림을 카툰 그림으로 바꿔 게임에 넣었다. 숫자 기준은 [ART_BIBLE 14절](../../../ART_BIBLE.md#14-카툰-화풍-2026-11-20).
예전 그림은 `assets/sprites/cat_frames_pencil/`로 옮겼고, 로컬 빌드의 시험 단추 "주인공 화풍: 카툰 / 예전"으로 바꿔 볼 수 있다.

## 다듬기 (2026-11-24, 디렉터 확인 반영)
디렉터가 0.25배 영상을 보고 지적한 4가지를 고쳤다. 슬라이딩·내리꽂기·피격 휘청 흐름은 통과라 자세는 그대로 두었다.

| 지적 | 고친 것 |
|---|---|
| 달리기가 토끼처럼 깡충거림 (6장 중 3장이 몸을 세우고 다리를 모은 자세) | 8장 갤럽으로 다시 뽑음 (`run_3.png`): 쭉 뻗기 → 공중(네 발 뜸) → 앞발 착지 → 앞발로 받치기 → 모으기 → 뒷발 착지 → 뒷발 박차기 → 늘어남. 몸은 늘 낮고 수평, 공중 장은 시트에서 뜬 높이(그림 24px) 그대로 둠. 몸 들썩임(코드 bob)은 한 바퀴 2번 → 1번(공중 장에서 가장 높음, 4게임px) |
| 피격 때 고양이 전체가 빨갛게 칠해짐 | 빨간 곱하기 색을 지우고 맞는 순간 60fps 2장(0.03초) 하얀 번쩍임: 셰이더 `scripts/cat_flash.gdshader`가 밝은 색(털·목도리)만 흰색으로 덮고 짙은 고동 선은 그대로 둠. 그 뒤 무적 깜빡임(투명)은 그대로 |
| 더블점프 시작(flip_tuck)이 공중에 서서 고개 숙여 인사하는 자세 | 앞구르기 4장을 다시 뽑음 (`flip_3.png`): 1장 = 머리를 배 쪽으로 당기고 앞발을 접어 등이 둥근 "말기 시작", 2~4장(C자·공·펴기)은 지난 흐름 그대로 |

### 0.25배 영상을 게임 프레임 단위로 본 결과 (2026-11-24, `video/*_zoom_slow.mp4`)
- 평지: 몸을 세운 장 없음, 머리 높이 고름. 다리를 몸 아래에 둔 장(run_3·4)은 한 바퀴에 3~4게임프레임 이어진다(아래 남은 문제 1).
- 피격: 빨간 칠 없음. 맞는 순간(히트스톱으로 멈춘 장) 하얀 장 1장 → 반투명 무적 깜빡임 → 튕김·휘청. 하얀 장은 털·목도리만 희고 선은 짙은 고동 그대로.
  처음에는 시간(0.03초)으로 재서 히트스톱 동안 6장이 하얬다 → 그린 장 수(2장)로 세게 고침. 영상에서 1장인 것은 첫 장이 히트스톱 전에 그려지기 때문으로 보임(1~2장 기준 안).
- 더블점프: 인사 자세 없음. 올라감 → 말기 시작(머리·앞발을 배 쪽으로) → C자 → 공 → 펴기 → 내려옴으로 이어진다.
- 땅 슬라이딩: 몸 낮추기 → 미끄러지기 → 일어나기 1·2 → 달리기, 툭 바뀌는 곳 없음.
- 목도리: 달리기·점프·몸 낮추기·구르기·미끄러지기·내리꽂기·피격·앉기 모두 목 뒤 짧은 두 가닥(앉기는 아래로 살짝 처짐, 튕김 장은 앞으로 날림). 등을 덮는 긴 띠 없음.

## 0.25배 영상을 장마다 본 결과 (2026-11-21 첫 만들기)
- 그림이 툭 바뀌는 곳: 없음. 땅 슬라이딩은 달리기 → 몸 낮추기(0.06초) → 미끄러지기 → 일어나기 1·2 → 달리기, 공중은 올라감 → 내리꽂기 → 눌림 → 미끄러지기로 이어진다.
- 발: 뜨거나 파묻히는 곳 없음 (모든 땅 장 발끝 = 기준선, 테스트로 확인). 튕김 장만 일부러 14px 떠 있음.
- 크기: 머리 크기를 맞춘 뒤 튀는 곳 없음.
- 목도리·귀: 접힌 귀는 모든 장 유지. 목도리 가닥은 달리기·점프·슬라이딩·내리꽂기가 같은 모양.

## 남은 문제 (숨기지 않음, 2026-11-24 기준)
1. 달리기 run_3(앞발로 받치기)은 앞다리가 곧게 서 있어 run_4(모으기)와 이어서 3~4게임프레임 동안 다리가 몸 아래에 모인다. 몸통은 수평이고 머리 높이도 그대로라 "몸을 세운 장"은 아니지만, 디렉터 기준(모으는 자세 1장, 많아야 2장)의 끝에 걸쳐 있다. 더 줄이려면 run_3만 앞다리를 비스듬히 다시 뽑으면 됨.
2. 몸 낮추기 장 키(77게임px)는 간판 아래 끝(70px)보다 높다. 간판 바로 밑에서 늦게 누르면 0.06초 동안 그림이 간판과 겹쳐 보인다(판정은 누른 순간부터 낮음).
3. 공중 눌림 장은 먼지까지 넣으면 캔버스(640)보다 넓어 왼쪽 먼지 끝을 흐리게 잘랐다.
4. 달리기 공중 장(run_1)은 그림에서 24px 떠 있고, 들썩임(4게임px)도 그 장에서 가장 높다. 땅 장들도 들썩임만큼(최대 약 3게임px) 뜰 수 있다(예전과 같은 방식).
5. 앞구르기 C자 장은 꼬리가 위로 크게 말린 모양이라 정지 화면에서는 어색하지만, 게임에서는 돌면서 0.03초쯤만 보인다.
6. 배경은 아직 색연필이라 짙은 고동 선의 주인공이 꽤 튀어 보인다(3단계에서 배경을 바꾸면 맞춰짐).
7. 시험 단추 "예전"은 카툰 달리기 8장을 예전 4장에 짝지어(뻗기 → run_2, 모으기 → run_0 등) 보여 줄 뿐이라, 예전 게임과 똑같지는 않다(예: 피격 때 흔들림이 없음).
8. 슬라이딩 중 화분에 맞으면 0.48초 동안 서 있는 피격 그림을 보인 뒤 미끄러지기로 돌아간다. 그동안 그림은 슬라이딩 판정보다 높다.
