## 1단계: 주인공 색
**원인 두 가지**
1. **번쩍임 셰이더(다듬기 a4ad5e3에서 추가)가 텍스처 색을 두 번 곱함** — `scripts/cat_flash.gdshader`가 `texture(TEXTURE, UV) * COLOR`를 썼는데 Godot 4의 fragment `COLOR`에는 이미 텍스처 색이 곱해져 있다. 색이 제곱돼 몸 `#FDB865` → 화면 `#F88828`(주황빨강), 연한 목도리 → 짙은 초록, 회갈색 먼 다리 → 검은 갈색. 그림 파일은 맞았고 화면에서만 진했다(파일과 Godot 가져오기 색이 `#FDB864`인 것을 확인). `COLOR`만 쓰게 고침.
2. **Codex 시트 색이 기준과 조금 달랐다** — run_3 시트가 목도리 `#73D097`, 몸 `#FCAE51`, 먼 쪽 다리 회갈색 `#AC977C`·짙은 갈색 `#9D501A`로 나왔고 자르기 단계(restyle·선 두껍게)에는 색을 맞추는 단계가 없었다(두껍게는 색을 바꾸지 않음, 목도리 `#75CF99` → `#70D098`). 자르기 단계에 "시트 색 k-means → 14-2 색표로 옮기기"(`cartoon_art.recolor`)를 넣어 41장 모두 다시 만듦. 먼 쪽 다리는 몸 그림자 `#FD9E54`·크림 그림자 `#FED5C4`.

## 2단계: 1-1 배경 카툰
- 층 구조·시차·이어 붙이기는 그대로: 하늘 → 구름 4(시차 0.05) → 먼 동네 띠(0.18, 번갈아 뒤집어 이음) → **나무 머리 띠**(0.22) → 건물(왼 캡 + 가운데 조각 + 오른 캡, 아래는 벽 색) → 장애물.
- 바꾼 것 (판단): 카툰은 흐림·그라데이션이 금지(14-4)라 **안개 4겹 대신 먼 안개 자리에 나무 머리 띠 한 겹**, 띠 아래는 평면 색 `#DECC99`(틈 아래). 하늘은 평면 `#C3E0FD` + 지평선 띠(화면 35~46%)만 두 색. 건물 아래 어두워지기·몸통 안개 없음, 벽 옆선은 `#331806` 3px. 예전 배경 그리기는 그대로("배경 화풍: 예전").
- 건물 3종(벽돌·크림 빌라·민트 타일): 높이 0.46배로 줄이고, 캡은 벽 바깥선이 그림 끝에서 9px(OVERHANG) 안쪽, 가운데 조각은 **짙은 선이 없는 세로줄(민벽)에서만** 잘라 어떤 순서로 이어도 창이 잘리지 않음. 빌라는 창 묶음이 한 덩어리라 "창 묶음 1 + 민벽 쉼표 2". 지붕 턱 띠 가운데에 8줄을 끼워 띠 가운데 = 고양이 발 내림(16px).
- 장애물(화분·실외기·물탱크·낮은 간판)·옥상 소품(굴뚝·안테나·난간): 예전 캔버스 크기 안에 비율대로 바닥 가운데 → 판정 높이와 그림 높이 관계가 예전과 같다. 소품은 예전처럼 0.8배·불투명도 0.6(장애물과 구별).
- **전봇대**: 꼭대기를 원통 변압기 통(폭 = 발판 판정 폭, 뚜껑 윗면 = 발 높이) + 가로대·애자로 바꿔 T자 탁자처럼 보이던 것을 고침. 카툰 전용 그리기(`_draw_pole_cartoon`, 상수 `CARTOON_POLE`은 그림에서 다시 재는 테스트 있음).
- 트램펄린 3상태: 예전 캔버스·행 상수 그대로(테 폭·발끝 97행·눌린 그물 바닥 80행), 튕김 칸만 솟은 그물 때문에 세로를 눌러 넣음.
- 아이템: 생선·황금 생선·하트 쿠키·금빛 방울. 판 속 생선은 카툰 한 가지(생선 강화 단계 그림 4단계는 예전 화풍에서만, 상점은 v0.10에서 다시).
