- 크기: 시트 하나 안에서 머리 크기가 같다. 공중 줄의 눌림 장은 폭이 446px(먼지 포함)로 넓지만 납작하게 눌린 자세라 그렇다.
- 남은 점: 미끄러지기 b의 앞발 엇갈림이 약하다(두 앞발이 거의 나란히). 미끄러지기 a의 위로 날리는 목도리 두 가닥이 작은 화면에서 귀처럼 읽힐 수 있다(초록이라 구별은 됨). 2단계(주인공 동작 전부)에서 다시 볼 것.
- 선 색: 세 시트 모두 `#331806`에서 각 채널 0x20 안. 3_C처럼 더 어두워지면 게임 그림으로 만들 때 `#331806`보다 어두운 픽셀을 올린다(14-1).

## 다시 뽑은 횟수: 2번 (5장 생성, 3장 사용)
- 기준 1차(`hero_ref_1.png`): 3/4 모습이 옆모습과 거의 같았다(얼굴 앞면이 안 보임). 지난 결과를 첨부하고 "몸을 45도 돌려 두 눈·두 볼·목도리 매듭·두 앞다리가 보이게, 나머지 칸은 그대로"를 덧붙여 2차.
- 피격 1차(`hit_1.png`): 맞는 순간이 정면으로 위아래로 눌리기만 해서 "뒤로 꺾임"이 없고 충격 별이 작았다. 튕김 장은 앞으로 뛰어오르는 것처럼 보였다. 1·4·5칸은 두고 2칸(옆모습 유지, 머리·가슴이 뒤로 밀려 등이 활처럼 젖혀짐, 머리보다 큰 충격 터짐)과 3칸(뒤로 기울어 왼쪽 위로 튕김, 앞쪽에 속도선 3개)을 고치라고 덧붙여 2차.
- 슬라이딩은 1번에 됨: 지난 시안의 문제 4가지(뾰족한 귀, 턱 밑 앞발, a·b·눌림이 같음, 앞쪽 먼지)가 모두 고쳐졌다.
