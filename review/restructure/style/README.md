# 화풍 시안 (2026-11-20, restructure 브랜치)

같은 장면을 세 화풍으로 그렸다. 게임 코드는 바꾸지 않았다. 결정 배경은 GAME_SPEC.md "2026-11-20 구조 전환" 절.

| 화풍 | 설명 |
|---|---|
| 1 | 지금 색연필 그대로 + 액션 효과만 굵고 진하게(집중선, 굵은 먹선, 진한 테두리) |
| 2 | 색연필 결은 남기고 바깥 선을 굵고 진하게, 색을 선명하게(중간) |
| 3 | 굵은 외곽선의 깔끔한 카툰(평면 색 + 그림자 한 단계) |

## 파일
- 비교: `compare_A.jpg`(능력 장면), `compare_B.jpg`(고양이 방), `compare_C.jpg`(슬라이딩 동작 시트), `compare_A_phone.jpg`(A를 폰 844x390 화면 높이에 맞춰 0.54배로 줄인 것. 양옆 회색은 실제 게임에서는 배경이 더 보이는 자리)
- 한 장씩: `<화풍>_<장면>.jpg` (A·B 1280x720, C 1280x640)
- 원본: `assets/concept/restructure_style/s<화풍>_<장면>.png` (내보내기 제외)
- 다시 만들기: `bash review/restructure/style/make_art.sh <화풍> <장면> <차례> [덧붙일 말]` → `python3 review/restructure/style/compose.py`. 요청문은 `prompts/`(common + style + scene), 첨부는 지금 게임 화면·주인공과 아기 설정·주인공 기준 그림.
- 구도를 같게 하려고 화풍 1을 먼저 그리고, 화풍 2·3은 같은 장면의 화풍 1 그림을 함께 첨부해 "구도는 그대로, 화풍만 바꿔"로 그렸다.

## 확인한 것 (직접 열어 봄)
- 주인공: 9장 모두 통통한 치즈 태비·접힌 귀·점 눈·볼 홍조·초록 목도리. 다만 C의 미끄러지기·내리꽂기 칸은 귀가 뒤로 날리면서 접힌 귀보다 뾰족한 귀처럼 보인다(세 화풍 공통).
- 그림 속 글자·숫자: 없음. A는 생선 아이콘 옆 빈 숫자 칸, 하트 3개, 얼굴 칸 2개(턱시도 칸 금빛 = 능력 사용 중). B는 얼굴 카드 6장, 선택 자리 2칸(1칸에 치즈 아기), 발바닥 출발 버튼.
- 구도: 세 화풍 A·B·C 모두 인물 자세·사물 배치·크기가 같다(비교 그림에서 확인).
- C: 두 줄 각각 같은 바닥선, 칸마다 고양이 크기가 같다. 미끄러지기 a·b는 먼지 모양만 조금 다르고 거의 같다(게임에 넣을 때 앞발·꼬리 차이를 더 줘야 함). 공중 줄의 "눌림" 칸도 미끄러지기와 비슷해 눌림이 약하다.
- 화풍 2는 줄무늬가 빨간 주황으로 진해지고 목도리가 밝은 초록이 됐다(선명하게 해 달라는 요청 범위로 봄).

## 다시 뽑은 횟수: 1번 (전체 10장 생성, 9장 사용)
