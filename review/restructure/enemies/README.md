## 게임 그림으로 만들 때 고칠 것 (v0.8.0 이후)
- 선이 기준보다 0.6~1.0px 가늘다 → 주인공 2단계처럼 게임 그림을 만들 때 선을 두껍게(`make_hero_frames.py` 방식) 하고 `#331806`보다 어두운 픽셀(시트 선의 3~6%)을 올린다.
- 쥐가 시트 축척 그대로면 폰에서 키 약 27px로 작다. 장면 시안처럼 시트보다 약 1.5배(주인공 머리의 절반)로 쓴다.
- 쥐 털이 회갈색(#A59E9B)이 아니라 연갈색으로 나왔다. 옥상 바닥 크림색과 대비는 충분해서 그대로 둬도 되지만, 화분 흙색과 겹치면 회색 쪽으로 다시 칠한다.
- 두목은 시트에서 주인공 키의 1.4배(날개 포함 폭 약 1.6배). 보스로서 존재감을 더 원하면 게임에서 1.3배 키운다.
- 동작 장 수는 시안이라 1장씩이다. 게임용은 날갯짓·달리기 반복 장을 따로 뽑는다.
