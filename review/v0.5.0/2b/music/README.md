# 배경 음악 후보 (아직 적용 안 함)

| `2_waddle_swing.ogg` | 114 | **뒤뚱 스윙.** 살짝 튕기는 박자에 우쿨렐레풍 긁기와 피치카토 멜로디, 글로켄 반짝임. 넷 중 가장 능청맞음 | 직접 작곡·합성 (`make_music.py swing`) |
