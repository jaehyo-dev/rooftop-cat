## 1. 고양이가 딱딱한 원인 (순위 = 화면에 보이는 시간 × 눈에 띄는 정도)

프레임 기록(motion_jump_strip.png 칸 아래 숫자)으로 확인한 사실과 고치는 방법.

| 순위 | 원인 (측정) | 고치는 방법 | 비용 |
|---|---|---|---|
| 1 | **달리기가 사실상 2모양의 깜빡임.** 4장 중 run_0≈run_3(오므림), run_1≈run_2(뻗음)이라 12번/초(처음 속도) "오므림↔뻗음"이 번갈아 나온다. 몸 위아래 들썩임이 없어 발끝이 늘 같은 선에 붙어 있다. 달리기가 플레이 시간의 대부분이라 가장 크게 느껴짐 | ① 코드: 발 디딤에 맞춘 몸 들썩임(한 바퀴에 2번, 3~5px, 발끝은 그대로 두고 그림만), 프레임이 바뀔 때 배율을 스프링으로 이어 "튀는" 대신 "출렁"이게. ② 그림: 달리기 6장 시트를 Codex로 다시(기준 그림 첨부, align_frames.py 정렬) | ① 코드만 (작음) ② 그림 6장 + 정렬·검수 (큼) |
| 2 | **공중에서 굳어 있음.** 손 뗀 뒤 착지까지 0.6초(36프레임) 동안 rise·fall 두 그림뿐이고 둘이 거의 같다. 내려올 때 배율이 0.92×1.10에 12프레임 고정(#56~#67). 꼭대기에서 rise→fall이 한 프레임에 바뀜(#43→#44) | 코드: 꼭대기 구간(|vy| < 200)에서 둥글게 부풀었다 다시 늘어나는 배율 곡선, 공중에서 아주 작은 "숨쉬기"(±2%, 2Hz), 낙하 늘어남을 고정값 대신 속도에 따라 계속 변하게. 더블점프 공중제비가 들어오면 공중 단조로움도 크게 줄어듦 | 코드만 (작음) |
| 3 | **탄력이 보간에 먹힘.** 착지 눌림은 1.22×0.80을 의도했는데 실제 최대 1.07×0.94(약 30%). `cat_view.gd`의 SMOOTH=22 지수 보간(프레임당 31%)이 0.14초짜리 짧은 눌림을 거의 지운다. 반대로 손을 뗄 때 takeoff 1.09×0.96 → rise 0.92×1.11로 4프레임 만에 "넓적 → 길쭉"이 튄다(#31→#35) | 코드: 배율을 지수 보간 대신 스프링(감쇠 진동)으로. 착지·이륙 같은 순간 효과는 스프링에 "충격"으로 넣어 넘쳤다 돌아오게(말랑함). takeoff→rise 전환은 같은 스프링이 이어 줌 | 코드만 (작음) |
| 4 | **웅크림이 땅이 아니라 공중에서 나옴.** 누르는 순간 이미 떠오르며(y 236→270) crouch를 4프레임 보여 줘 "땅을 박차는" 느낌이 없다 | 코드: 웅크림을 0.03초로 줄이고, 뛰는 순간 세로로 늘어나는 충격(0.88×1.18)을 스프링에 넣음 + 발밑 먼지(3번 체크리스트). 입력 지연은 늘리지 않는다 | 코드만 (작음) |
| 5 | **꼬리·귀가 늦게 따라오지 않음.** 통그림이라 꼬리가 몸과 한 덩어리로 움직임 | ① 코드: 셰이더로 꼬리 쪽(프레임 왼쪽, 앵커 기준 x < -150) 픽셀만 세로 속도 반대로 살짝 휘게(지연 0.08초). 번지면 버림. ② 그림: 자세마다 꼬리 위·아래 2벌 | ① 셰이더 (중간, 실험) ② 그림 10장 이상 (큼) |
| 참고 | 떨어짐(flail)은 흔들림이 있어 상대적으로 괜찮음. 다만 같은 SMOOTH 보간이 흔들림(±4%, ±10도)을 반쯤 줄인다 | 3번 스프링으로 같이 해결 | |

기울기는 v0.2.2 결정대로 되살리지 않는다. 단, 더블점프 공중제비의 회전은 "기울기"가 아니라 정해진 연출(0.36초 한 바퀴)이라 예외로 둔다 (사용자 승인 필요 항목).

**추천: 1~4는 v0.5.0 2단계에서 코드로 한다(새 그림 없음).** 스프링 하나(`scripts/logic/` 순수 계산, 테스트 가능)에 착지·이륙·프레임 전환·공중제비를 모두 넣는 구조. 결과 GIF를 보고도 달리기가 딱딱하면 그때 달리기 6장 그림(1-②)을 v0.6.0 손맛 단계에서 한다. 5-①은 실험해 보고 번지면 뺀다.

## 3. 빨래줄 타이밍 트램펄린

| 항목 | 값 |
|---|---|
| 판정 | 줄에 닿을 때마다 판정. 닿으면 0.08초 줄에 실려 있다가(로직 높이는 줄에 고정, 처짐은 그림만) 튕긴다 → 닿은 뒤에도 누를 수 있음. 실려 있는 동안 발이 다음 옥상에 걸치면 바로 착지 |
| 누름 창 | 닿기 0.18초 전 ~ 닿은 뒤 0.08초 (0.26초). **새로 누른 것만**(계속 누르고 있던 손은 안 침). 닿기 전 누름은 "마지막 새 누름 뒤 지난 시간"으로 판정 (예측 불필요) |
| 너무 이른 누름 | 닿기 0.18~0.28초 전 누름은 더블점프로 새지 않고 "빨랐어!" 실패로 보여 줌 (더블점프 막는 창 0.28초) |
| 퍼펙트 창 | 닿기 0.04초 전 ~ 닿은 뒤 0.04초 (0.08초 = 60fps 약 5프레임) |
| 튕김 높이 (줄 위로) | 안 누름 80 → 줄이 느슨해져 이 틈에서는 더 이상 받아 주지 않음(떨어짐) / 누름 230 / 퍼펙트 330 |
| 더블점프 충전 | 누름·퍼펙트 튕김이면 충전. 안 누름은 충전 안 함 |
| 줄 위 생선 | 줄 위 420 (퍼펙트 330 + 더블점프로만 닿음). 보너스일 뿐 건너기에는 필요 없음 |
| 한 틈에 닿는 횟수 | 보통 2번 (처음 속도: 옥상 끝에서 뛰어 줄까지 약 330, 누름 튕김 한 번 332, 틈 852~1018). 더블점프로 줄 멀리 내리면 1번 |

| 다음 옥상 너비 | 줄 끝에서 퍼펙트 튕김 + 더블점프 최대로 가도 그 옥상 안에 내려앉는 너비 (지금은 더 높이 튕김 기준이라 지나칠 수 있음) |

"눌러!" 안내:
- 몇 번: **매 판 처음 2개 줄 틈**에서만. (누적 성공으로 끄는 저장 방식은 만들지 않음: 저장 형식이 바뀌고, 2개면 숙련자에게도 짧음)
- 모양: 닿기 0.5초 전부터 줄의 닿을 자리에 **줄어드는 동그라미**(코드 도형, 갈색 + 밝은 테두리)가 그려지고 닿는 순간(퍼펙트 가운데)에 고양이 발 크기로 딱 맞는다. 고양이 머리 위에 Gaegu Bold "눌러!" 말풍선(HUD와 같은 갈색·테두리). 결과로 "좋아!"/"퍼펙트!" 글자가 0.4초 떠올랐다 사라짐(퍼펙트는 반짝임 + 소리). 안내가 없는 줄에서도 결과 글자는 나옴
- 동그라미는 타이밍 정보 자체라 "억울하지 않게"에 가장 효과적. 그림이 아닌 UI 도형이라 ART_BIBLE 2번 예외에 해당

- 전봇대: 판 앞뒤 틈의 상한을 "한 번 점프의 75%" → **"더블점프 거리의 75%"**로 바꾼다(지금 공식은 위 너비를 못 만들어 전봇대가 아예 안 나옴). 판에 서면 더블점프가 충전되므로 "점프+더블 → 판 → 점프+더블"이 기본, 잘 누르면 한 번 점프로도 됨. 높이 차 ±110 거리(더블): 오르막 636/1010/1381, 내리막 724/1150/1572 (속도 430/690/950)
- 일반 틈은 그대로(한 번 점프 × 0.5~0.8). 더블점프는 일반 틈에서 실수 만회용
- 판 앞뒤 틈은 **보이는 거리(고양이 앞 940 - 발 범위 - 여유 = 800) 이하**로 한 번 더 자른다: 뛰는 순간 판이 화면 안에 보여야 함. 최고 속도에서도 120 + 800 × 2 = 1720 ≥ 1698이라 판을 만들 수 있음. 자동 테스트 추가
- 줄 틈은 화면보다 넓어도 줄이 틈 시작부터 보이므로 괜찮음
- 봇은 더블점프를 최적 시점(착지 직전)이 아니라 "꼭대기 + timing 실수"에 쓰게 한다 (사람처럼, 난이도를 낮게 재지 않게). 꼭대기에서 써도 최대 거리의 0.86~0.88배라 판 앞뒤(75%)는 넉넉
- v0.4.1 봇 기준값은 코드를 바꾸기 전에 먼저 잰다. 시드 고정 테스트가 깨지면 기대값 대신 성질(건넘/못 건넘)로 바꾼다

밸런스 봇 계획 (`tests/balance_bot.gd`):
1. 더블점프 규칙: 착지할 때 계획한 점프가 다음 발판에 못 미칠 것으로 계산되면, 가장 멀리 가는 시점(계산으로 찾음)에 timing 실수를 더해 더블점프. 넓은 틈은 항상 더블점프 사용
2. 빨래줄: 닿는 시점(계산) + N(0, timing)에 누름 → 창 안이면 누름/퍼펙트, 밖이면 실패. 줄을 노린 착지 위치는 지금처럼
3. 비교: 시드 1~30, 초보·익숙함·숙련, 최대 900초, v0.4.1(지금 코드로 먼저 측정해 표에 남김)과 v0.5.0의 한 판 길이 가운데값 + 특수 틈별 성공률(줄 닿을 때 성공률, 판 성공률)
