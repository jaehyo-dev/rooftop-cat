## 음악과 음량

`assets/audio/mochi_walk.ogg`: 찹쌀떡 산책 28마디 56.9초 (후보 A·B 16마디 + 새 C 8마디 + A 뒤 4마디). C는 북·베이스를 줄이고 피치카토·글로켄으로 쉬어 가는 구간. 곡 끝 소리는 처음에 감겨 있고, 인코딩 뒤 이음매 샘플 차이 0.002. 곡 -21.4 LUFS. 음악 -5dB, 효과음 -5dB(착지만 +4dB). 이전 곡 `neighborhood.ogg`는 남겨 둠.

## 안개

M1 지금 / M2 크림 75%, 맨 앞 덮는 높이 2/3 / M3 채도 낮은 크림·옅은 하늘색, 맨 앞 불투명도 0.7, 덮는 높이 1/2. M2·M3는 먼 살구색 안개(far)도 같이 옅게 했다: 그대로 두면 옅어진 mid·near 뒤로 살구색이 모래 땅처럼 보였다. 채도는 모두 고양이(평균 0.41)보다 낮다.
