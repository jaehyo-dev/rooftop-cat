# v0.5.0 2a-2: 옥상 끝 트램펄린 + 발·그림자 붙이기

브랜치 `v0.5.0-double-jump`, 버전 번호는 그대로(v0.4.1). PLAN 11번 1·2 (공중제비 몸 말기·스프링 모션·그림자 A·안개 45%·효과음은 2b).

## 1. 발·그림자 붙이기 (`feet_compare.png`)

- 건물 3종(벽돌·빌라·타일)의 가운데 조각을 줄마다 재면 모두 같은 구조: 4줄 어두운 뒤 선(판정선 바로 아래) → 6~26줄 밝은 윗면 → 29~30줄 어두운 앞 선. 윗면 가운데 = 약 16.5줄.
- 그래서 **고양이·그림자·아이템·안내 동그라미·말풍선을 판정선보다 16px 아래**에 그린다(`world_view.gd`의 `FOOT_SINK`). 판정선은 그대로.
- 전봇대 판: 판 윗면이 그림 7~14줄이라 판 그림을 내려 윗면 가운데(10.5줄)가 고양이 발 높이에 오게 함.
- 트램펄린: 다리 끝을 옥상 서는 자리(판정선 + 16)에 두고, 밟음 그림의 꺼진 그물 바닥이 다리 끝보다 10px 위라 판정 그물 높이를 옥상 + 10(`TRAMP_LIFT`)으로 맞춤.
- 달리기 4장: 가장 아래 불투명 픽셀이 모두 발(run_0 앞·뒷발, run_1 앞발, run_2 앞발, run_3 뒷발)이라 네 발이 다 뜬 장은 없음 → 고치지 않음.
- 자동 테스트: 건물 3종 가운데 조각의 뒤 선·앞 선을 찾아 내림값이 윗면 가운데 ±2 안인지, 밟음 그림 그물 바닥 높이가 판정 그물 높이 ±2 안인지 확인.

## 2. 트램펄린 수치

판정 창은 2a 빨래줄과 같음: 닿기 0.18초 전 ~ 닿은 뒤 0.15초 누름, 닿기 전후 0.04초 퍼펙트, 닿기 0.18~0.28초 전 누름은 "빨랐어!"(점프·더블점프로 새지 않음), 새로 누른 것만.

| 항목 | 값 |
|---|---|
| 자리 | 넓은 틈 앞 옥상 끝(끝에서 10 안쪽), 판정 너비 150, 옥상 높이 240 이하에서만 |
| 닿음 | 달려 들어가 몸 가운데가 왼쪽 끝 + 60(그물 가운데쯤)을 지날 때, 또는 위에서 내려와 발이 걸칠 때 |
| 튕김 높이 (그물 위로) | 안 누름·이른 누름 80 (가로 속도 그대로, 다시 안 받아 줌) / 누름 300 / 퍼펙트 420 |
| 발사 가로 속도 | 트램펄린마다 계산해 저장: 누름은 가장 일찍 튕기는 자리(뒷발 끝만 걸침)에서도 다음 옥상 끝 + 60에, 퍼펙트는 그보다 160 더 멀리 내려앉는 속도. 내려설 때까지 유지 |
| 틈 너비 | 못 건너는 최소(점프 + 더블점프로도 못 건넘) ~ 최소 + 100 |
| 다음 옥상 너비 | 가장 늦게 튕긴 자리에서 누름·퍼펙트 + 더블점프를 가장 멀리 써도 안 지나치는 너비 |
| 퍼펙트 생선 길 | 퍼펙트 궤적 중 누름 꼭대기보다 80 이상 높은 구간 (누름으로는 못 먹음) |
| 더블점프 | 누름·퍼펙트면 다시 생김. 안 누름이면 남은 더블점프를 써도 못 건넘(테스트) |

체공: 안 누름 0.46초, 누름 0.87초, 퍼펙트 1.03초. 넓은 틈은 "점프 + 더블점프로도 못 건넘"이라 체공만으로는 못 건너서, 트램펄린은 높이와 함께 **앞으로 밀어 주는 발사대**로 만들었다.

### 그림 모양 변화 (`tramp_timing.gif`)

평소 → **밟음**(고양이가 실려 있는 동안 + 튕긴 순간 한 프레임) → **튕김**(0.12초, 위로 볼록) → 평소가 출렁이며 0.5초. 그림 사이는 다리 끝 기준 세로 배율로 이음. 퍼펙트는 더 깊게 눌림(0.84배, 누름 0.92배)·더 크게 솟음(+28%, 누름 +14%). 바뀌는 프레임은 자동 테스트가 로직 step 단위로 확인(닿기 전 step = 평소, 닿는 step = 밟음).
