# v0.5.0 2a: 규칙과 수치 (더블점프 · 빨래줄 누름 판정 · 넓은 틈 · 세로 카메라)

브랜치 `v0.5.0-double-jump`, 버전 번호는 그대로(v0.4.1). 그림·효과는 최소: 공중제비는 웅크린 그림 회전만, "눌러!" 동그라미·말풍선과 결과 글자만 넣음.
먼지 고리·별·소리·반짝임·스프링 모션·그림자 A·안개 45%는 2b.

## 밸런스 봇 비교 (시드 1~30, 최대 900초, `tests/balance_report.gd`)

한 판 길이 가운데값(초)과 특수 틈 성공률. 목표: 가운데값이 v0.4.1의 0.7~1.5배, 초보 줄 틈 성공률 70% 이상.

| 실력 | v0.4.1 | 2a 계획 수치 그대로 | 2a 조정 뒤 (최종) | 배율 |
|---|---|---|---|---|
| 초보 | 51 | 26 | **47** | 0.92 |
| 익숙함 | 356 | 127 | **376** | 1.06 |
| 숙련 | 900 | 848 | **900** | 1.00 |

| 실력 | 줄 틈 성공 v0.4.1 → 2a | 판 틈 성공 v0.4.1 → 2a | 줄에 닿을 때 누름·퍼펙트 (2a) |
|---|---|---|---|
| 초보 | 99% → **87%** | 84% → **87%** | 94% |
| 익숙함 | 100% → **100%** | 93% → **92%** | 100% |
| 숙련 | 100% → **100%** | 98% → **98%** | 100% |

v0.4.1은 줄을 밟기만 하면 건넜으므로 줄 틈 성공률이 거의 100%였다. 2a에서는 누름 타이밍이 필요하다.
떨어진 곳(30판): 초보 줄 15 · 판 14 · 일반 1, 익숙함 판 27 · 줄 1, 숙련 판 3.

### 조정 과정 (PLAN 4번 순서: 누름 창 → 줄 틈 너비 폭 → 판 앞뒤 비율 → 일반 틈 여유)

| 단계 | 바꾼 값 | 초보 / 익숙함 / 숙련 (초) | 초보 줄 | 메모 |
|---|---|---|---|---|
| 계획 그대로 | - | 26 / 127 / 848 | 61% | 줄에서 거의 다 떨어짐 (늦은 누름) |
| 1 누름 창 | 닿은 뒤 0.08 → 0.12초 | 27 / 262 / 900 | 72% | |
| 2 줄 틈 너비 폭 | 0.5 → 0.3 | 29 / 248 / 900 | 75% | |
| 3 판 앞뒤 비율 | 0.75 → 0.65 | 변화 없음 → 0.75로 되돌림 | | 판 앞뒤 틈은 "못 건너는 최소"로 정해져 0.75 상한에 안 걸림 |
| (계획 밖) | 줄을 못 만드는 높이(240 위)면 전봇대 대신 일반 틈 | 36 / 314 / 900 | 73% | 전봇대가 v0.4.1보다 약 40% 잦아졌던 것을 되돌림 |
| 1 누름 창 | 닿은 뒤 0.12 → 0.15초 | 37 / 314 / 900 | 84% | 초보는 이제 판에서 떨어짐 |
| 3 대신 | 판 틈 폭(최소 + 200 → + 100) | 38 / 340 / 900 | 85% | |
| (계획 밖) | 판 너비 200→120 를 240→140 | **47 / 376 / 900** | 85~87% | 기존 테스트(초보 40~150초)를 맞추려고 |

일반 틈 여유(4번째)는 일반 틈에서 떨어지는 판이 거의 없어(더블점프가 만회) 손대지 않았다.

## 계획에서 바꾼 수치

| 항목 | PLAN | 2a | 이유 |
|---|---|---|---|
| 줄 누름 창 (닿은 뒤) | 0.08초 | 0.15초 | 봇 초보 실패가 거의 다 늦은 누름. 줄에 실려 있는 시간도 같이 0.15초 |
| 줄 틈 너비 폭 | 누름 튕김 x 0.5 | x 0.3 | 닿는 횟수 줄이기 |
| 줄 위 생선 | 420 | 460 | 420이면 퍼펙트만으로 먹힘 (몸 타원 + 먹는 거리 70 > 44). 460은 퍼펙트 + 더블점프로 닿음 |
| 판 너비 | 200 → 120 | 240 → 140 | 판 앞뒤 틈이 한 번 점프 거리만큼 넓어져 초보 판 성공률이 떨어짐 |
| 판 틈 폭 | 최소 + 200 | 최소 + 100 | 판 앞뒤 비율(0.75)이 실제로 안 걸려서 대신 조정 |
| 줄 못 만드는 높이 | (정하지 않음) | 일반 틈으로 | 전봇대 빈도를 v0.4.1과 같게 |
| 더블점프 최고 높이 | 130 | 130 + 4 | 꼭대기 중력 0.5배라 4픽셀 더 오름 (계산 그대로 둠) |
| 줄 닿기 전 누름 판정 | (지정 없음) | 닿는 순간 바로 튕김 | 닿기 전에 누른 경우 0.08초 기다리지 않고 바로 판정 (반응이 늦어 보이지 않게) |
