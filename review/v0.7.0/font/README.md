# 글꼴 비교 (v0.7.0-shop, 2026-11-13)

사용자 요청: 지금 글꼴(Gaegu)은 동글한 건 좋은데 손글씨라 삐뚤빼뚤하다. 동글하면서 또박또박한 글꼴로 바꾸고 싶다.
**비교만 했다. 게임 코드·assets·버전은 그대로.** (글꼴 파일 `*.ttf`는 이 폴더에 받아만 두고 커밋하지 않음: `.gitignore`)

## 3. 맞춘 값 (글자 크기 위계는 ART_BIBLE 13-3 그대로: 제목 48, 본문 34, 보조 30, 숫자 40, 큰 숫자 72)

글꼴마다 **글자 사이**와 **줄 높이(위·아래)** 만 맞췄다. 크기마다 같은 비율이 되게 em(글자 크기의 몇 배)으로 정함.

| 글꼴 | 굵기 나눔 | 글자 사이 | 줄 위 / 아래 더하기 | 본문 34px에서 (사이, 위, 아래) |
|---|---|---|---|---|
| Gaegu (지금) | Bold 하나 | -4px (모든 크기, `menu_font.tres`) | 0 / 0 | -4, 0, 0 |
| 나눔스퀘어라운드 | 44px 이상(제목·큰 숫자·HUD 큰 글자) **ExtraBold**, 31~43px(본문·숫자) **Bold**, 30px 이하(보조·경험치) **Regular** | -0.03em | -0.113em / +0.008em | -1, -4, 0 |
| 주아 | Regular 하나 (원래 굵음) | -0.03em | 0 / 0 | -1, 0, 0 |
| 고운돋움 | Regular 하나 (굵기가 하나뿐) | -0.06em | -0.356em / -0.092em | -2, -12, -3 |

- 줄 높이: 글꼴마다 줄 상자 높이가 달라(Gaegu 1.0em, 나눔 1.105em, 주아 1.0em, 고운돋움 1.448em) 그대로 두면 칸 안 글자 위치가 위아래로 밀린다. 줄 상자를 Gaegu처럼 1.0em로, 한글 가운데가 줄 상자 위에서 0.426(Gaegu 값)에 오게 위·아래를 더했다.
- 글자 사이: 34px로 0/-1/-2/-3px를 찍어 보고 낱말이 묶여 보이는 값으로 골랐다.
- 같은 글자 크기에서 실제로 보이는 크기: 한글 높이 Gaegu 0.84em → 나눔 0.94em(+12%), 주아 0.81em, 고운돋움 0.93em. **숫자 높이 Gaegu 0.50em → 나머지 셋 0.72~0.73em(+45%)**. Gaegu 숫자는 원래 작은 글꼴이라, 바꾸면 숫자가 확 커 보인다(HUD·가격·지갑).

## 6. 내 의견 (결정은 사용자)

- "동글 + 또박또박"에 가장 가까운 건 **주아**: 지금 화면 크기·칸에 그대로 맞고, 귀여움을 유지하면서 삐뚤빼뚤함이 사라짐. 파일도 가장 작음.
- **나눔스퀘어라운드**는 가장 잘 읽히고 굵기로 위계를 줄 수 있지만, 바꾸면 보이는 크기가 커져 미션 쪽지·결과 카드 여백을 다시 맞춰야 하고 느낌이 덜 그림책 같다.
- **고운돋움**은 가늘어서 이 게임(굵은 색연필 그림, 주황 버튼 위 글자)에는 맞지 않음. 후보에서 빼는 걸 권함.
- 고르면 할 일: 글꼴을 `assets/fonts/<이름>/`에 라이선스와 함께 넣기, `menu_font.tres`·`main.tscn`·`world_view.gd`의 글꼴 바꾸기, ART_BIBLE 13-3 글자 사이 값 갱신, CREDITS.md, 가장 긴 값 검사·눈 검수 다시.

## 7. 다시 만드는 법

1. 임시 git worktree에 `tools/worktree.patch`를 적용(HUD·테마 글꼴을 바꿀 수 있는 `swap.tres`로, `tools/qa_web.gd`에 `?qa=font&font=` 모드 추가)하고 후보 글꼴을 `assets/fonts/cand/`에 복사.
2. 글꼴마다 `menu_font.tres`·`swap.tres`를 그 글꼴 본문 굵기로 바꿔 검수용 웹 빌드(`2c-polish/export_qa.sh`와 같은 방식)를 따로 내보냄 (실행 중에 글꼴 자원을 바꾸면 글꼴 캐시 오류가 나서 빌드를 나눔).
3. `PLAYWRIGHT=… CHROME=… node tools/font_web.mjs <빌드> <캡처> <gaegu|nsr|jua|gowun> <pc|phone>`
4. `python3 tools/compose.py <캡처> compare tools/crops.json`
5. 글자 검사: `godot --headless --path . -s <절대경로>/tools/glyph_check.gd -- <글꼴.ttf>...`
