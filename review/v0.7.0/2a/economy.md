# v0.7.0 2a 봇 경제·강화 효과 (2026-11-11, 윈도우 WSL)

실제 `Perks`로 밸런스 봇을 돌린 결과. 원본 출력은 `economy_raw.md`, 실행은 `economy.gd`(13분 39초, 판 수 약 1,000).
- 1번 표: 실력별 시드 30, 최대 900초.
- 날짜별: 하루 5판, 판이 끝날 때마다 **가장 싼 다음 강화**를 산다. 판마다 그때 강화 단계로 봇이 실제로 플레이(시드 = 1000 + 판 번호).
- 미션 수입·부스터 지출은 PLAN 4-2와 같은 어림값: 미션 하루 3,185(초보 2,157, 일일 2개·주간 2개만 깸), 부스터 −900/일. 미션은 2b에서 실제 봇 진행으로 다시 잰다.

- PLAN 4-2 어림(보통 13일, 70% 18일, 초보 37일)보다 보통 플레이어가 3일 늦다. 어림은 "강화를 산 만큼 수입이 직선으로 오른다"고 봤는데, 실제로는 판마다 수입이 크게 흔들리고(익숙함 하루 8,469 ~ 21,724) 수입을 늘리는 강화(질주·털실)가 다른 강화와 같은 순서로 사져서 늦게 오른다.
- 목표 "약 2주"에 보통 16~19일. **가격은 그대로 둔다**(사용자 승인 값). 2c 사용자 플레이 뒤 저장의 `stats.runs`·`stats.fish_total`로 실제 한 판 수입을 보고 한 번 더 맞춘다(PLAN 4-2). 내리는 건 플레이어에게 손해가 없다.
- 첫날 9단계를 산다(300원짜리 6개 + 800원짜리 3개): 처음 며칠 자주 사는 재미는 의도대로. 마지막 사흘은 하루 1~2단계.
- 미션 비율: 보통 21~26%(목표 약 20%), 초보 34~43%(못하는 사람일수록 미션이 받쳐 줌, 의도대로).

**판 길이·난이도 (전부 10단계)**
- 익숙함: 평균 240 → 273초(+14%), 가운데 164 → 244초, 하위25% 103 → 206초. 일찍 끝나던 판(90~160초)이 첫 쿠키 70초와 질주 6초 덕에 살아남는다. 평균 증가는 PLAN 3-3 어림(+14%)과 같다.
- 숙련: 평균 +3%, 가운데는 오히려 640 → 623초(시드 차이). 오래 버티는 사람에게는 강화가 거의 버티기를 안 준다(150초 뒤 아이템 6배 간격 그대로).
- 초보: +7%(평균), 끝난 이유가 하트 0 → 떨어짐으로 옮겨 감(쿠키가 하트를 채워 줘서). 떨어짐 자체는 강화와 무관.
- **질주 뒤 3초 안 떨어짐**: 질주가 6초로 길어져도 늘지 않음(익숙함 2 → 2, 초보·숙련 0). 착지 옥상 규칙이 남은 거리 기준이라 그대로 맞다(PLAN 3-2).
- → 난이도가 무너지지 않았다고 판단. 버티기는 "조금"(익숙함 +14%) 늘고 주로 점수가 오른다(가운데값 약 8배).
