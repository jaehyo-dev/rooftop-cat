## 고치지 않은 것 (다음에 볼 것)

- 폰에서 작은 글자: 쪽지의 경험치 `+15`(22px → 폰 약 12px), 줄여 넣은 99,999/99,999(18px → 약 10px). 진짜 미션 목표는 10,000이 가장 커서 실제로는 23px 정도로 보임. 미션 쪽지 전체 크기 조정은 화면 개편이라 이번 범위 밖.
- 왼쪽 위 HUD `BEST 9999999`는 쉼표 없음 (v0.6.0 HUD, 메뉴 화면이 아니라 이번 검사 범위 밖).
- 시험 패널(왼쪽 아래 "시험")은 배포 전에 지울 임시 코드라 기본 글꼴 그대로.
