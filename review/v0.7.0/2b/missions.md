# v0.7.0 2b 미션 봇 측정 (2026-11-12, 윈도우 WSL)

밸런스 봇의 실제 판 기록(`MissionTracker`, 게임과 같은 세기)으로 미션이 얼마나 깨지는지 잼. 실행 `missions.gd`(약 4분), 원본 `missions_raw.md`(고친 뒤), `missions_raw_before.md`(PLAN 5번 처음 수치).
- 판: 실력별 150판(시드 1~150, **강화 0단계**, 최대 900초). 강화를 사면 판이 길어지니 실제보다 조금 어렵게 잰 값.
- 플레이어: 20명 x 8주, 매일 실제 `Missions.refresh`로 뽑고 **일일 3개를 다 깰 때까지만**(하루 최대 6판) 한다. 판마다 가장 싼 강화를 사고, 다 샀으면 하루에 부스터 하나. 바꾸기는 안 씀.
- "보통 플레이어" = 익숙함 봇.

- 보통 주간 처음 65%: `w_runs`(25판)는 일일만 하면 하루 1~2판이라 8주 내내 못 깸(37/37), `w_upgrade`(강화 5번)는 2주쯤 강화를 다 사면 **영영 못 깸**(20/37).
- 초보 "익숙함 이상 뒤": 초보 봇도 3% 판에서 1,500m를 넘어, 8주 동안 대부분의 날(927/1120일)이 "익숙함 이상"이 된다. 그 뒤로는 통조림·방울·어려움 미션이 나와 4판 안 61%. 실제 사람은 1,500m를 넘을 즈음이면 실력이 늘었을 것이고, 막히면 바꾸기(200)가 있다 → 그대로 둠 (사용자 판단 필요 시 2c 플레이 뒤 다시 봄).
- 초보 주간 6일 58%(목표 없음): 못 깬 것은 `w_fish_20k`(17/32), `w_perfect`(17/40), `w_gold`(8/34).
